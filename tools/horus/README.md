# حورس (Horus) — مولّد اللوجو

> **Firebase:** لما الموقع يتحوّل لـ Firebase، حورس بيفضل على الدالة دي. بتتحقق من توكن Firebase (RS256، محليًا بمفاتيح جوجل العامة) لو الـ Secret `FIREBASE_PROJECT_ID` متحط، وبتفضل بتقبل توكن Supabase كمان (الرجوع ممكن في أي وقت). المحادثات المحفوظة بتتخزّن في Firestore (من المتصفح)، مش من الدالة. الخطوات في `tools/firebase/README.md`. **إعادة نشر الدالة مش بتتعمل قبل تأكيدك.**

مصدر واحد لكل الملفات: `build_horus.py`. الرسم والحركة والألوان كلهم فيه.

```bash
# ملفات SVG (ثابت + متحرك، فاتح/داكن/تلقائي)
python3 tools/horus/build_horus.py out/
# تحديث الموقع: js/horus.js وكتلة الـ CSS في آخر css/pages.css
python3 tools/horus/build_horus.py out/ --js js/horus.js --css css/pages.css
```
بعد التحديث ارفع `VERSION` في `sw.js` وأعد بناء الملف الواحد (`tools/build.py`).

- `badge` = العين جوه قوس اللوح مع شمس إمحتب (الأيقونة). `mark` = العين لوحدها (خطوط).
- ألوان الموقع: الفاتح `#1E3F8F` لازورد، `#E3A93A` ذهبي، `#167370` فيروزي. الداكن `#E0B25A` / `#FFD98A` / `#4FD0C8`.
- الحالات (classes على الـ svg): `hz-in` `hz-idle` `hz-think` `hz-found`.
- «حورس» كنص: Reem Kufi (خط الموقع)، بيتحط كنص حي جنب اللوجو، مش داخل الـ SVG.

# حورس الشات العايم (للمذاكرة، مش للامتحان)

زرار عايم في ركن الشاشة بيفتح بانل جانبي. الطالب بيسأل في المنهج، والسيرفر بيدوّر في كتب الأقسام وبيرجّع إجابة مصاغة بالعربي المصري المهذّب.
**الموقع نفسه مفيهوش مفتاح Gemini**: بيكلّم دالة Supabase باسم `horus` بتوكن حساب الطالب، والدالة هي اللي بتكلّم Gemini.

## الأجزاء
| الجزء | فين |
|---|---|
| الواجهة (زرار + بانل + أنيميشن + محادثة محفوظة) | `js/horus-chat.js` + `css/horus-chat.css` + `IM.AI.chat` في `js/ai-config.js` |
| زرار «اسأل حورس عن السؤال ده» (لما مفيش شرح جاهز، في التدريب بس) | `IM.aiBox` في `js/ai.js` |
| الدالة (Deno) على Supabase | `tools/horus/edge/src/*` (متنشرة باسم `horus`، `verify_jwt:false`، بتتحقق من الطالب بنفسها) |
| قاعدة البيانات | `tools/horus/sql/horus.sql` (اتطبّق خلاص: `horus_passages` الكتب، `horus_cache` الكاش المشترك، `horus_usage` العدّادات، `horus_chat` المحادثات) |
| نصوص المصادر (الكتب) | `tools/horus/export_passages.py` ← `tools/horus/out/` **(خاص، مش بيترفع على الريبو ولا في الزيب)** |
| برومبتات الشات | `tools/horus/edge/src/prompts.js` (منفصلة عن برومبتاتك السبعة في `tools/ai/prompts` اللي ما اتلمستش) |

## اللي لازم تعمله إنت (٣ خطوات)
1. **مفتاح Gemini**: Supabase Dashboard ← Edge Functions ← **Secrets** ← Add: الاسم `GEMINI_API_KEY` والقيمة مفتاحك (من Google AI Studio). **ماتحطوش في أي ملف ولا تبعتهولي.**
2. **الكتب**: Table Editor ← جدول `horus_passages` ← Insert ← **Import data from CSV** ← ملف `horus-passages.csv` (875 مقطع). أو شغّل ملفات `horus-passages-<المادة>.sql` الأربعة في SQL Editor. لازم يتعمل مرة واحدة، وتعيده لو الكتب اتغيّرت.
3. **التجربة**: ارفع الـ `site.zip` الجديد، وافتح من متصفحك `…/Anatomy360/?horus=1` (لازم تكون مسجّل بجوجل، وحفظ التقدّم شغّال). جرّب سؤال، وبعدين من جهاز تاني بنفس الحساب. لما تتأكد غيّر في `js/ai-config.js` الـ `pilot:true` لـ `pilot:false` وارفع الزيب.

اختبار سريع للدالة من غير الموقع: افتح `https://uaxreejcuantlwtuadtv.supabase.co/functions/v1/horus` في المتصفح، المفروض يرجّع `ready:{gemini:true,db:true}` بعد الخطوتين ١ و٢ (قبلهم بيرجّع false لواحد منهم).

## إعدادات اختيارية (Secrets تانية، ليها قيم افتراضية)
| الاسم | الافتراضي | معناه |
|---|---|---|
| `HORUS_USER_DAILY` | 10 | أقصى عدد أسئلة جديدة للطالب في اليوم (بتوقيت القاهرة). الأسئلة اللي ليها إجابة في الكاش المشترك مابتتحسبش |
| `HORUS_GLOBAL_DAILY` | 400 | أقصى عدد استدعاءات Gemini في اليوم لكل الطلبة (سقف تكلفة). لما يخلص الطالب بيشوف «حورس عليه ضغط» ومابيتحسبش عليه |
| `HORUS_USER_RPM` | 8 | أقصى طلبات للطالب في الدقيقة |
| `HORUS_MODELS` | `gemini-3.5-flash-lite,gemini-3.1-flash-lite` | ترتيب الموديلات (لو الأول رفض بنجرّب اللي بعده). **غيّره حسب اللي بيشتغل على مفتاحك** |
| `HORUS_THINKING` | (فاضي) | إعداد thinking لـ Gemini كـ JSON لو عايز تقلّل التكلفة/الزمن |
| `HORUS_ORIGINS` | رابط github.io وفيرسل | المواقع المسموح لها تكلّم الدالة (CORS) |
| `HORUS_OFF` | (فاضي) | `1` = إيقاف طارئ لحورس كله من غير ما ترفع حاجة |

## إزاي بيشتغل (باختصار)
طلب الطالب ← تحقق من الجلسة ← حد الدقيقة ← **الكاش المشترك** (إجابة اتولّدت قبل كده لنفس السؤال بنفس الصياغة) ← الحد اليومي ← البحث في الكتب (BM25 نفس منطق `tools/ai/imai/retrieve.py`، والأسئلة العربي بتتحوّل لكلمات إنجليزي بنداء Gemini صغير) ← Gemini ← **فحص الرد**: JSON سليم، الرد عربي، والاستشهادات لازم تكون مقاطع حقيقية اتبعتت (وإلا بيتحوّل لـ«معرفة عامة»). إجابة المعرفة العامة بتبدأ بجملتك: «الإجابة غير موجودة بشكل واضح في المصدر المتاح…». أي فشل بيرجّع السؤال للطالب (مابيتحسبش).

## قيود لازم تبقى واضحة (صدق)
- **محدش جرّب حورس مع Gemini الحقيقي لسه** (بيئتي مفيهاش إنترنت). كل المنطق اتجرّب على نسخة وهمية من Gemini وعلى Postgres حقيقي. أول تجربة حقيقية بتاعتك هي اللي هتأكد جودة الصياغة وأسماء الموديلات.
- **الكتب بتغطّي مواضيع محدودة** (875 مقطع). السؤال خارجها بيتجاوب «معرفة عامة» وبيتعلّم كده للطالب بوضوح.
- **قفل الامتحان جوه الموقع بس**: حورس مخفي في شاشة الاختبار ومقفول طول ما فيه امتحان مفتوح، لكن مفيش حاجة تمنع الطالب يفتح جوجل أو ذكاء اصطناعي تاني في تبويب تاني أو على موبايله. ده حد تقني مش بنقدر نعدّيه، والالتزام مسؤولية الطالب.
- التكلفة والحدود المجانية لـ Gemini تقديرات: راجع صفحة الأسعار وحدود مفتاحك قبل ما تفتح للكل. تقدير: سؤال جديد واحد ≈ ٤ آلاف توكن دخول + ٥٠٠ خروج.
- المحادثة بتتحفظ على الجهاز وعلى حساب الطالب (جدول `horus_chat`، RLS، بتتمسح مع الحساب). الخصوصية والشروط اتحدّثوا بده (`tools/legal/build_legal.py`).
